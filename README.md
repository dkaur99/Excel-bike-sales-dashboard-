# Bike Sales Dashboard (Excel)

## Overview
An interactive Excel dashboard that explores which customer characteristics are linked to bike purchases. Built with pivot tables, pivot charts, and slicers.

## Dataset
Sample bike buyers dataset, records with fields such as marital status, gender, income, education, occupation, commute distance, region, age, and whether a bike was purchased.

## Tools
Microsoft Excel (Pivot Tables, Pivot Charts, Slicers, Nested IF formulas)

## What I Did
- Kept a raw data sheet as a backup and worked on a separate copy
- Cleaned the data: removed duplicates and replaced abbreviations with full labels (Find & Replace)
- Created age brackets using nested IF formulas
- Built pivot tables and pivot charts for average income, commute distance, and age group against bike purchases
- Combined the charts into one dashboard with slicers for marital status, region, and education that filter all charts at once

## Questions Explored
- Does average income differ between bike buyers and non-buyers?
- Is commute distance related to buying a bike?
- Which age groups buy the most bikes?
